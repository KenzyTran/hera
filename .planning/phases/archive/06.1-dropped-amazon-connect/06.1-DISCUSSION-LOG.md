## Contact Flow caller UX (AWS-NAT-04)

### Sub-question 1: Greeting + barge-in

| Option | Description | Selected |
|--------|-------------|----------|
| Brand greeting + barge-in ON | Polly: "Welcome to Hera Apple Store. How can I help?" → Get Customer Input (Interruptible=true) → Lex/Lambda → Play KB answer (Interruptible=true) → Disconnect. Demo-friendly: shows Hera brand + caller can interrupt long Polly responses. | ✓ |
| Minimal: Lex prompt + barge-in ON | No greeting — Get Customer Input with inline prompt "How can I help you today?" → Lex/Lambda → Play answer → Disconnect. Fewer blocks (3 vs 4) but no brand surface. | |
| Greeting + barge-in OFF | Same brand greeting but Interruptible=false on both Get Customer Input + Play Prompt. Caller must wait for Polly to finish. Stable playback but feels unnatural. | |

**User's choice:** Brand greeting + barge-in ON (Recommended)

### Sub-question 2: Error/silence handling

| Option | Description | Selected |
|--------|-------------|----------|
| Minimal: single attempt + disconnect | Get Customer Input timeout (~5s silence) OR Lex/Lambda error → Polly "Sorry, I could not hear you. Please call back." → Disconnect. Single error path. ~4-6 blocks total per SPEC's 4-block estimate. | ✓ |
| Re-prompt 1 time | Silence/error → "I didn't catch that. Please ask again." → loop back to Get Customer Input once → if fails again → "Sorry, please call back." Disconnect. Friendlier UX but +2-3 blocks + 1 counter; more complex Contact Flow JSON. | |

**User's choice:** Minimal: single attempt + disconnect (Recommended)
**Notes:** Brand greeting "Welcome to Hera Apple Store. How can I help?" + error prompt "Sorry, I could not hear you. Please call back." both locked verbatim in D-69 + Specific Ideas. Final block count ~5-6 (slightly above SPEC's "4 blocks" estimate due to conditional error branch; not a scope drift, just a refinement).
