# Phase 3 — UI Design Contract

> Visual and interaction contract for the public web widget on the instructor demo URL. Generated by gsd-ui-researcher from CONTEXT.md D-28 / D-29 + REQUIREMENTS.md WID-01..06 / DEM-01..03. Verified by gsd-ui-checker.

> Surface in scope: `frontend/index.html`, `frontend/app.js`, `frontend/audio-capture-worklet.js`. Vanilla HTML/CSS/JS, no framework, no build step beyond `bin/deploy-widget.sh` sed-replace of the WSS URL (D-27). Single-page, single-purpose voice demo — not a marketing site.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual design system, no shadcn — stack is vanilla HTML/CSS/JS, no React/Vite/Next.js) |
| Preset | not applicable |
| Component library | none (raw DOM elements + scoped CSS in `<style>` block of `index.html`) |

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gap between status pill and label, transcript line padding |
| sm | 8px | Gap between transcript entries, button internal padding (vertical) |
| md | 16px | Default element spacing (banner padding, card padding, button vertical margin) |
| lg | 24px | Section padding, gap between record button and transcript |
| xl | 32px | Card outer padding, gap between banner and card |
| 2xl | 48px | Page-top breathing room above the card |

Exceptions:
- **Record button hit target: 56px height** (not on the 8-point scale, but mandated by WCAG 2.5.5 minimum touch-target ≥44×44px and Apple HIG touch comfort; the button is the primary interaction in the entire UI).
- **Status pill height: 24px** (compact inline element, paired with 14px label text).

## Typography

Exactly 4 sizes, exactly 2 weights. System font stack only.

| Role | Size | Weight | Line Height | Used For |
|------|------|--------|-------------|----------|
| Body | 16px | 400 (regular) | 1.5 | Hint text, error messages, banner body |
| Label | 14px | 400 (regular) | 1.4 | Status pill text, transcript timestamps, button-state caption when present |
| Heading | 20px | 600 (semibold) | 1.3 | "Hera Voice Agent" page title |
| Display | 28px | 600 (semibold) | 1.2 | Reserved — not used in Phase 3 (single-page widget has only one heading); declared so the scale is complete and Phase 5 docs can reuse the token |

Transcript pane uses `ui-monospace, SFMono-Regular, Menlo, monospace` at 14px / 1.5 (carry-forward from Phase 2 baseline) — monospace is intentional so spoken text and control frames align readably. This is the only deviation from the system stack and applies only inside `#transcript`.

## Color

60/30/10 split with Apple-Store light branding (D-28). Hex values verbatim from CONTEXT.md `<specifics>` where given; secondary/accent locked to Apple's published interface tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f5f5f7` | Page background (Apple-Store light surface) |
| Secondary (30%) | `#ffffff` | Card surface holding the record button + transcript; banner background |
| Accent (10%) | `#0071e3` | Record button (idle border + hover state); user transcript label color; primary CTA emphasis |
| Destructive | `#e74c3c` | Error state border on record button; error pill background; error transcript line color |

**Accent reserved for** (explicit list — no other use):
1. Record button border in **idle** state (1px) and full background in **listening** state.
2. User transcript line text color (`User:` prefix + utterance).
3. Banner left-border accent stripe (4px solid bar to draw the eye to demo notice).

**Destructive reserved for:**
1. Record button border in **error** state (2px solid).
2. Status pill background when WS / mic / agent timeout fails.
3. Error transcript line color.

**Neutral grey palette** (not counted in 60/30/10 — these are achromatic, used for hierarchy):
- `#1d1d1f` — primary text (heading, body, transcript user text)
- `#6e6e73` — Apple grey for agent transcript lines, hint text, subtitle (locked in CONTEXT.md `<specifics>`)
- `#d2d2d7` — card border, transcript pane border
- `#86868b` — disabled button text, timestamp text

**Per-record-button-state color spec** (D-28 mandates 5 distinct states):

| State | Background | Text | Border | Notes |
|-------|------------|------|--------|-------|
| idle | `#ffffff` | `#1d1d1f` | 1px solid `#0071e3` | Label: "Record" |
| connecting | `#fff8e1` | `#5d4e00` | 1px solid `#e8a000` (yellow pulse @ 1.2s ease-in-out) | Label: "Connecting..." |
| listening | `#e74c3c` | `#ffffff` | 1px solid `#c0392b` | Label: "Recording (click to stop)" — carry-forward from Phase 2 |
| speaking | `#e8f1fc` | `#0071e3` | 1px solid `#0071e3` | Label: "Agent speaking" — non-interactive (button disabled while agent speaks) |
| error | `#ffffff` | `#1d1d1f` | 2px solid `#e74c3c` | Label: "Retry" |

WCAG AA contrast: every foreground/background pair above clears 4.5:1 for body text (verified: `#1d1d1f` on `#ffffff` = 16.1:1; `#ffffff` on `#e74c3c` = 4.5:1; `#0071e3` on `#e8f1fc` = 6.7:1; `#5d4e00` on `#fff8e1` = 9.8:1).

## Interaction & Motion

Minimal motion. No splashy transitions.

| Interaction | Behavior |
|-------------|----------|
| Record button hover (idle state) | Background fades to `#f5f5f7` over 120ms ease-out. No scale, no shadow lift. |
| Record button focus (keyboard) | 3px solid `#0071e3` outline, offset 2px (NOT `outline: none`). Required for WCAG 2.4.7. |
| Record button click | No motion; instant state swap. |
| Connecting state pulse | 1px border on `#e8a000` pulses opacity 0.5 ↔ 1.0 over 1.2s `ease-in-out` infinite. CSS `@keyframes`, no JS. |
| Listening state | Static red — NO pulsing waveform, NO blinking dot (D-28 explicitly excludes waveform visualizer). |
| Transcript new line | No fade-in; instant append. Auto-scroll uses `scrollTop = scrollHeight` (already in Phase 2 baseline). |
| Error → retry transition | Click "Retry" → state returns to idle synchronously; no fade. |

`prefers-reduced-motion: reduce` MUST disable the connecting-state pulse (replace with static `#e8a000` border).

## Accessibility

WCAG 2.1 AA target. The widget is a public demo and may be used by users with assistive tech.

| Concern | Decision |
|---------|----------|
| Record button | `<button>` element (not `<div role="button">`). `aria-pressed` reflects listening vs idle. `aria-busy="true"` while connecting. `aria-disabled="true"` while speaking. |
| Status pill | `role="status"` with `aria-live="polite"` so state transitions are announced to screen readers. |
| Transcript | `role="log"` with `aria-live="polite"` and `aria-atomic="false"` (only new lines are announced). |
| Banner | `role="region"` with `aria-label="demo notice"`. |
| Color contrast | All foreground/background pairs in §Color clear 4.5:1 (verified above). Status pill text never relies on color alone — the text label always names the state. |
| Keyboard | Record button reachable via Tab. Space + Enter both toggle. Workshop link in banner reachable via Tab. |
| Focus rings | 3px solid `#0071e3` outline, 2px offset. Never `outline: none` on focusable elements. |
| Screen reader for state changes | Status pill `aria-live="polite"` carries the canonical state announcement; record button `aria-pressed` toggles in lockstep. Avoid duplicate announcements by keeping the transcript auto-append at `aria-live="polite"` (not "assertive"). |
| Errors | Error transcript line + status pill update simultaneously; both are `aria-live="polite"`. The button label change ("Retry") provides a third visual anchor. |

## Out of Scope (deferred — do NOT add)

Per CONTEXT.md `<deferred>` and D-28 explicit exclusions:

- Modal onboarding / first-run tutorial
- Inline FAQ
- Waveform visualizer / audio level meter
- Sound-effect cues (button click, agent-ready chime)
- Dark mode toggle (Apple-Store light only for v1)
- Avatar / persona illustration
- Any branded logo asset (the heading text is the brand)
- Analytics, error reporting (Sentry et al.), session replay
- Per-instructor cost-cap configuration UI
- Custom domain / favicon (v1 ships default `*.cloudfront.net` URL with no favicon)
- Internationalization of the widget UI itself (chatbot speech and UI both English per locked stack)
