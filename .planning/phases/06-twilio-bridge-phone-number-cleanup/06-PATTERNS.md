### `infra/modules/twilio_bridge/src/main.py` (FastAPI entrypoint)

**Analog:** `agent/hera_agent/main.py` (lines 1-67, full file)

**Pattern to copy verbatim** (the FastAPI app shape with `/ping` health route + WS route + `WebSocketDisconnect` bounded try/except):
```python
"""FastAPI entrypoint for the Hera Twilio Bridge.

Exposes two routes on port 8080:
- GET           /ping     : App Runner health check (returns {"status":"Healthy"}).
- WebSocket     /twilio   : Twilio Media Streams terminator. One per phone call.

D-67: X-Twilio-Signature HMAC validation is enforced at the WebSocket upgrade
(the HTTP request that becomes the WS) before accept().
"""

from datetime import datetime, timezone

from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from loguru import logger

from src.bridge import handle_twilio_call
from src.config import validate_twilio_signature

app = FastAPI(title="hera-twilio-bridge", version="0.1.0")

_BOOT_TIME = int(datetime.now(tz=timezone.utc).timestamp())


@app.get("/ping")
async def ping() -> dict:
    """App Runner health probe (HTTP 200 -> status=Healthy)."""
    return {
        "status": "Healthy",
        "time_of_last_update": _BOOT_TIME,
    }


@app.websocket("/twilio")
async def twilio_endpoint(websocket: WebSocket) -> None:
    """Per-call Twilio Media Streams handler. Closes when Twilio sends `stop` or peer hangs up."""
    # D-67: validate X-Twilio-Signature before accept() — reject anonymous traffic.
    validate_twilio_signature(websocket)
    await websocket.accept()
    logger.info("Twilio WS accepted: %s", websocket.client)
    try:
        await handle_twilio_call(websocket)
    except WebSocketDisconnect:
        logger.info("Twilio WS disconnected")
```

**Reuse pattern from agent main.py** (lines 26, 53, 58-61):
- `_BOOT_TIME` captured at module import (line 26).
- `await websocket.accept()` then bounded `try`/`except WebSocketDisconnect` (lines 53, 58-61) — the project mandates "the only try/except is the documented disconnect path" per AGENTS.md.

### `infra/modules/twilio_bridge/src/bridge.py` (per-call coroutine)

**Analog A** (SigV4 mechanics ONLY — server-side request signing instead of presigned URL): `infra/modules/widget_presigner/src/handler.py` (lines 21-44, 58-70)
**Analog B** (Pipecat pipeline shape — async coroutine that pumps a websocket): `agent/hera_agent/pipeline.py` (referenced for shape only — not pasted here)

**SigV4 pattern from widget_presigner handler.py lines 21-44** — **REUSE the imports + constants verbatim**:
```python
from urllib.parse import quote

from botocore.auth import SigV4QueryAuth   # widget uses Query (presigned URL); bridge will use SigV4Auth (header) — see below
from botocore.awsrequest import AWSRequest
from botocore.session import Session

REGION = os.environ["AWS_REGION"]
RUNTIME_ARN = os.environ["AGENTCORE_RUNTIME_ARN"]

SERVICE = "bedrock-agentcore"
HOST = f"bedrock-agentcore.{REGION}.amazonaws.com"

ENCODED_ARN = quote(RUNTIME_ARN, safe="")
WSS_PATH = f"/runtimes/{ENCODED_ARN}/ws"
WSS_URL_BASE = f"wss://{HOST}{WSS_PATH}?qualifier=DEFAULT"
HTTPS_URL_BASE = f"https://{HOST}{WSS_PATH}?qualifier=DEFAULT"

_session = Session()
```

**Critical DEVIATION from widget_presigner handler.py lines 58-70:** the bridge does NOT mint a presigned URL. It signs an outgoing WebSocket UPGRADE request server-side. Replace `SigV4QueryAuth(creds, SERVICE, REGION, expires=...)` (which encodes the signature into URL query params for the browser) with `SigV4Auth(creds, SERVICE, REGION)` (which encodes the signature into the HTTP `Authorization` header that goes on the upgrade request).

**Skeleton** (no analog for this exact shape — App Runner long-running coroutine that bridges two WS):
```python
import asyncio
import base64
import json

import websockets
from botocore.auth import SigV4Auth
from botocore.awsrequest import AWSRequest
from fastapi import WebSocket

from src.resample import twilio_to_sonic, sonic_to_twilio


def _sign_upstream_headers(session_id: str) -> dict:
    """Build SigV4-signed headers for the AgentCore upgrade. Mechanics mirror
    widget_presigner/src/handler.py:_presign_wss_url, but as Authorization-header
    auth on an outgoing WS upgrade instead of a presigned-URL for the browser.
    """
    creds = _session.get_credentials().get_frozen_credentials()
    request = AWSRequest(method="GET", url=HTTPS_URL_BASE)
    request.headers["X-Amzn-Bedrock-AgentCore-Runtime-Session-Id"] = session_id
    SigV4Auth(creds, SERVICE, REGION).add_auth(request)
    return dict(request.headers.items())


async def handle_twilio_call(twilio_ws: WebSocket) -> None:
    """One coroutine per call. Holds upstream WSS open for the call duration."""
    # 1. Wait for Twilio `start` event to capture CallSid and stream metadata.
    start_msg = await twilio_ws.receive_text()
    start = json.loads(start_msg)
    call_sid = start["start"]["callSid"]
    stream_sid = start["start"]["streamSid"]

    # 2. Open upstream WSS to AgentCore Runtime, signed with this call's session id.
    headers = _sign_upstream_headers(call_sid)
    async with websockets.connect(WSS_URL_BASE, additional_headers=headers) as upstream:
        # 3. Bidi pump.
        await asyncio.gather(
            _pump_twilio_to_sonic(twilio_ws, upstream),
            _pump_sonic_to_twilio(upstream, twilio_ws, stream_sid),
        )
```

**RESEARCH.md 06-RESEARCH.md lines 270, 488-507** confirms the `websockets.connect(..., additional_headers=...)` shape is the canonical async-Python upstream-WSS pattern.

### `infra/modules/twilio_bridge/src/resample.py` (μ-law <-> Int16 transform)

**Analog:** **NONE.** This is greenfield audio code.

**RESEARCH.md 06-RESEARCH.md provides verbatim copy material** (lines 186-204 + 624-631):
```python
"""μ-law 8kHz <-> Int16 16kHz two-way resample (D-59).

audioop on Python 3.13 comes from the audioop-lts PyPI shim. API is verbatim
identical to the stdlib audioop removed in 3.13 per PEP 594.

ratecv state must be threaded across frames within a call to avoid filter
discontinuities at frame boundaries (RESEARCH §Pitfall 2). The per-call
coroutine in bridge.py owns the state dict.
"""

import audioop


def twilio_to_sonic(mulaw_8k: bytes, state) -> tuple[bytes, object]:
    """μ-law 8kHz inbound from Twilio -> Int16 16kHz to AgentCore upstream."""
    pcm16_8k = audioop.ulaw2lin(mulaw_8k, 2)
    pcm16_16k, new_state = audioop.ratecv(pcm16_8k, 2, 1, 8000, 16000, state)
    return pcm16_16k, new_state


def sonic_to_twilio(pcm16_in: bytes, in_rate: int, state) -> tuple[bytes, object]:
    """Int16 in_rate inbound from AgentCore -> μ-law 8kHz to Twilio.

    in_rate is 16000 or 24000 — planner adds Wave-1 probe task to confirm
    the AgentCore data-plane WSS framing rate (CONTEXT.md D-59 open caveat).
    """
    pcm16_8k, new_state = audioop.ratecv(pcm16_in, 2, 1, in_rate, 8000, state)
    mulaw_8k = audioop.lin2ulaw(pcm16_8k, 2)
    return mulaw_8k, new_state
```
